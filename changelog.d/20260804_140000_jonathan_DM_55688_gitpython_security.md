### Bug fixes

- Update `gitpython` to 3.1.58, which resolves four high-severity advisories that applied to templatebot. The most directly relevant is [GHSA-94p4-4cq8-9g67](https://github.com/advisories/GHSA-94p4-4cq8-9g67) (CVSS 7.5), environment-variable exfiltration through a crafted URL passed to `Repo.create_remote()` / `Remote.add()` — templatebot calls `create_remote()` from `GitClone.add_remote()` in `templatebot.storage.gitclone` when it attaches an authenticated remote to a cloned repository, so this code path is exercised during project creation. Also fixed: [GHSA-r9mr-m37c-5fr3](https://github.com/advisories/GHSA-r9mr-m37c-5fr3) (git option guard bypass via single-character kwarg token smuggling), [GHSA-6p8h-3wgx-97gf](https://github.com/advisories/GHSA-6p8h-3wgx-97gf) (`--template` omitted from the unsafe clone-option denylist, enabling arbitrary command execution via clone hooks), and [GHSA-fjr4-x663-mwxc](https://github.com/advisories/GHSA-fjr4-x663-mwxc) (arbitrary file overwrite via `git diff --output` argument injection).
